# Best Next Guess

Free helper for daily 5-letter word puzzles: enter your green, yellow and gray letters to see every possible answer, the odds, and the smartest next guess. Works in hard mode and knows which answers were already used.

Live at https://bestnextguess.com

Past answers update automatically every day (see `.github/workflows/update-past.yml`).
